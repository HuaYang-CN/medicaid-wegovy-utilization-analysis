
# Medicaid Wegovy Reportability and Comparative Analysis Code

## Release information

Version: v2.0.0-rc1

GitHub repository:
https://github.com/HuaYang-CN/medicaid-wegovy-utilization-analysis

GitHub release:
https://github.com/HuaYang-CN/medicaid-wegovy-utilization-analysis/releases/tag/v2.0.0-rc1

Zenodo archived record:
https://doi.org/10.5281/zenodo.23444656

This public repository contains analysis code, selected frozen
non-identifiable inputs, source documentation, model diagnostics,
and supporting materials for the associated Medicaid Wegovy
utilization study.

The portable verification commands check specified frozen
inputs and saved numerical results. They do not independently
refit every historical model. Some archived historical scripts
have undergone static validation only.

See INDEPENDENT_QA.md for the detailed reproducibility
scope and limitations.
