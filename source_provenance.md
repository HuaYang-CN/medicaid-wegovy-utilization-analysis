# Source provenance

source_code_provenance.csv fingerprints every recovered source and its adapted copy. Source archive copies retain all functions of selected relevant computational modules, with AST formatting and personal-path string replacement only. They are historical programs for inspection, not a claim that every historical entry can run unchanged with this compact package. Their audit-report dependencies and complete raw extracts are intentionally not bundled. Do not import historical entry modules: some have top-level writes. Use run.py for supported portable operations.

The original acquisition date and original execution environment are NOT_VERIFIABLE. Located historical scripts are not falsely represented as proven exact originals for every saved legacy result. In particular, Table S9 stays SAVED_HISTORICAL_NOT_REVALIDATED. The independently audited Stage04 computations have retained source identities and frozen result hashes. Input files for primary, timings/FE, channels, LOO, 11-quarter scenarios and P1-51 are included as thin aggregate records. Full raw CMS extracts are omitted; current official downloads cannot be assumed byte-equivalent. Source URLs and original hashes are in data/source_versions.csv. No data were downloaded for R2.

portable/c10.py extracts the actual R2 calculation functions, replacing only IO and the resume reader for unused object labels; it is a current adapter, not a recreated historical script. portable/figures.py reuses actual plot coordinates/values and replaces the local Times New Roman font file with standard PDF Times-Roman. Deliverable figures themselves remain the accepted unchanged PDFs. Full C10 covariance and diagnostics are under saved/c10; reference objects are under saved/reference. No hidden-count recovery is attempted.
