
# Code availability

The analysis code and selected frozen, non-identifiable inputs
supporting this study are publicly available at:

https://github.com/HuaYang-CN/medicaid-wegovy-utilization-analysis

The GitHub release corresponding to the archived code is:

https://github.com/HuaYang-CN/medicaid-wegovy-utilization-analysis/releases/tag/v2.0.0-rc1

The associated Zenodo archived record is available at:

https://doi.org/10.5281/zenodo.23444656

The repository includes code for data processing, statistical
models, sensitivity analyses, model-identifiability diagnostics,
leave-one-state-out analyses, figures, tables, and quality checks.

The portable verification workflow checks frozen inputs and
saved numerical results. It does not independently refit every
historical model. Some historical analysis scripts have been
preserved or statically checked without complete end-to-end
re-execution.

Detailed reproducibility boundaries are documented in
README.md and INDEPENDENT_QA.md.
